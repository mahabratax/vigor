# Vigor assistant: compact conversation

## Revision after the dashboard review

The expanded decision workspace was rejected because it competed with the monitoring dashboard. Keep its useful actions and move its detail into an on-demand conversation. The dashboard gets a compact command bar and one contextual suggestion. A right-side native dialog holds the conversation; mobile uses the full viewport. Evidence, additional matches and workflow details start collapsed. Only the current answer exposes actions.

Use Glacier #EDF7F5, White #FFFFFF, Deep canopy #143E38, Jade #348575, Mist #BDE6DD and Water light #91CBD7 as the assistant's material palette, retaining the existing semantic text colors and Plus Jakarta Sans. One glass-like seed icon and a restrained jade/cyan edge identify the assistant; the surrounding dashboard stays quiet. Text stays left aligned. Motion responds only to opening the drawer, respects reduced motion, and never pretends to be model processing.

Critique: a second table of priorities would repeat the rejected report pattern. A large chat hero would consume the same space under another name. The revised design has one narrow launcher, no dashboard KPI strip, no persistent evidence table, and a single current response with progressive disclosure. Typed topic lookup and suggested questions are functional local record lookup, explicitly labelled; no simulated model output, voice button, attachment button or typing delay is introduced.

The following notes describe the earlier functional foundation. Its data safeguards remain in effect; the joined queue/evidence presentation below is superseded by this compact design.

The dashboard's first job is to help a greenhouse operator choose useful work and verify its result. The previous AI readiness panel only described a connection prerequisite. Replace it with a record-driven decision workspace, while keeping model access explicitly disconnected.

## Visual direction

Keep Vigor's existing Plus Jakarta Sans and its type scale. The palette remains Dew #F3F7F4, White #FFFFFF, Leaf ink #20352B, Canopy #1D593F, Water #357E88 and Attention #C87C2A, through semantic tokens that also support the existing dark theme. Content is left aligned. One joined priority list and evidence panel creates the hierarchy; independent decorative KPI cards and an empty chat interface would obscure the work. At small widths, the priority selector precedes the selected decision and all actions wrap.

The distinctive content is the relationship between crop health, blocked harvest stock, resource checks and receipts. Spend visual emphasis on the selected decision and its workflow. Evidence links, quantities and statuses must explain what happens next. No artificial health score, model confidence, claimed savings, or automatic hardware action.

## Behavior and review

The local rules derive priorities from existing records. Operators can inspect evidence, assign a linked care task, record work, and revisit the source to verify the outcome. The existing normalized care task is the only operational task record; its stable key links it to the source decision. Revalidate evidence before creation, preserve permission checks and reject cross-greenhouse writes. Completion of a care task never closes a pest case. Missing or expired telemetry cannot support a crop condition claim.

Gemini is not connected. Keep AI input preparation in Settings and explain that today's assistant uses deterministic rules. Preserve the future provider contract and all existing review forms. Validate pure domain rules, interactive states at four viewport settings and real browser SQLite persistence; report separately that browser rendering and WebGL cannot be verified without the browser-control capability.
